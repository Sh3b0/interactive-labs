# Default Workshop

Hi there! If you can see this page with a live terminal on the right, you've successfully started the lab environment.

Workshop files are read from `/app/workshop` in your `labenv` container or VM.

## Getting Started

1. You can load custom workshop files using the button above, it asks for a GitHub URL (e.g., `https://github.com/owner/repo/tree/branch/subdir/workshop`).

2. Or, manually download/clone workshop files to `/app/workshop` using the terminal on the right, replacing the content of this directory, then refresh the page.

3. Or, mount a workshop directory from `docker-compose.yaml` (when deploying labenv as a container) then restart the container.

    ```yaml
    labenv:
      volumes:
          - /path/to/workshop:/app/workshop
    ```

4. Or, mount a workshop directory in `labenv.yaml` (when deploying labenv as a VM)

    ```yaml
    mounts:
      - location: "{{.Home}}/workshop"
        mountPoint: /app/workshop
        writable: true
    ```

    > Note that [relative paths are not supported](https://github.com/lima-vm/lima/issues/893) for `mounts.location`, but you can reference some [template variables](https://github.com/lima-vm/lima/blob/20dbdc0e8da292fa9b82178affb6310b0835a996/templates/default.yaml#L54) if needed.
