# Empty Workshop

Hi there! If you see this page within the lab environment, it means that no particular workshop was loaded. Workshop files are expected in `/app/workshop` in your container or VM.

- Container mode: mount a workshop directory in `docker-compose.yaml`

  ```bash
  labenv:
    volumes:
        - ./workspace:/home/ubuntu
        - /path/to/workshop:/app/workshop
  ```
- VM mode: mount a workshop directory in `labenv.yaml` ([relative paths are not supported](https://github.com/lima-vm/lima/issues/893))
  
  ```bash
  mounts:
  - location: "{{.Home}}/workshop"
    mountPoint: /app/workshop
    writable: true
  ```
